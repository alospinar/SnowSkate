# SnowSkate

SnowSkate es un juego 2D de snowboard desarrollado en Unity como proyecto de aprendizaje. El jugador debe atravesar el nivel, controlar sus giros y aprovechar distintos power-ups para llegar a la meta.

## Cómo jugar

- Usa `A` y `D` para girar al personaje.
- Usa `W` para activar el impulso de velocidad y `S` para mantener la velocidad normal.
- Llega a la línea de meta sin chocar contra la pista.
- Consigue power-ups para mejorar temporalmente la velocidad o el control de giro.
- Realiza giros completos para aumentar tu puntuación.

## Mecánicas

- Movimiento basado en físicas 2D.
- Control de rotación y equilibrio en la pista.
- Impulso de velocidad.
- Power-ups temporales de velocidad y torque.
- Detección de choques y reinicio del nivel.
- Línea de meta con efectos de partículas.
- Selección entre dos personajes.
- Sistema de puntuación por giros.

## Tecnologías

- Unity `6000.4.8f1`
- C#
- Unity 2D Physics
- Unity Input System
- Universal Render Pipeline 2D
- Cinemachine
- TextMesh Pro
- ScriptableObjects para configurar los power-ups

## Ejecutar el proyecto

1. Abre el proyecto con Unity `6000.4.8f1`.
2. Abre la escena `Assets/Scenes/Level 1.unity`.
3. Pulsa **Play** en el editor.
4. Selecciona un personaje y comienza el recorrido.

La escena `Level 1` está configurada como la escena inicial del proyecto.

## Objetivo del proyecto

SnowSkate forma parte de mi proceso de aprendizaje en desarrollo de videojuegos con Unity. El proyecto reúne práctica de programación de mecánicas, físicas 2D, diseño de niveles, interfaces de usuario, partículas y organización de datos mediante ScriptableObjects.
